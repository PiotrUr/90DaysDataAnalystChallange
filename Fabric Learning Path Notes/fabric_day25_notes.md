## 🧠 Key Concepts
🔹 Fabric Warehouses are cloud-native, scalable, and fully managed data warehouses  
🔹 Use T-SQL to create tables, insert data, and run queries  
🔹 Built-in support for columnstore and rowstore indexes  
🔹 Integration with OneLake for seamless data connectivity  
🔹 SQL Endpoint enables fast access from Power BI, Notebooks, and external tools

## 🔧 What I did
🔹 Created a new Warehouse in Fabric  
🔹 Created and populated a table using T-SQL  
🔹 Queried data with standard SQL syntax  
🔹 Explored system views and metadata  
🔹 Connected the Warehouse to Power BI for analysis

## 📌 Summary
Fabric Warehouses offer familiar SQL development with the scale and simplicity of the cloud. They provide a central and optimized environment for enterprise-grade analytics, with native support for Power BI and OneLake integration.
