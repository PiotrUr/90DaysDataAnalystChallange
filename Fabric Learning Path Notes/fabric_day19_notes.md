# 📘 Microsoft Fabric – Study Notes (Day 19)

## 🔷 Module: Orchestrate processes and data movement with Microsoft Fabric
🔗 [Link to module](https://learn.microsoft.com/en-us/training/modules/use-data-factory-pipelines-fabric/?WT.mc_id=cloudskillschallenge_b696c18d-7201-4aff-9c7d-d33014d93b25)

### 🧠 Key Concepts:
🔹 **Pipelines** in Fabric orchestrate data movement and transformation through connected activities  
🔹 Common activities include:  
  🔸 **Copy Data** – move data between sources and destinations  
  🔸 **Dataflow Gen2** – perform transformations using Power Query  
🔹 Pipelines support parameters, dependencies, and triggers (manual/scheduled)

### 🔧 What I practiced:
🔹 Created a new pipeline in Fabric Data Factory  
🔹 Used **Copy Data** to move CSV file into Lakehouse  
🔹 Built and configured **Dataflow Gen2** for transforming the imported dataset  
🔹 Connected activities and tested the pipeline run  
🔹 Set up monitoring to validate execution and troubleshoot failures

### ✅ Summary Takeaways:
🔹 Data Factory in Fabric makes building ETL pipelines approachable and powerful  
🔹 **Dataflow Gen2** simplifies data transformation without writing code  
🔹 Monitoring tools are integrated and intuitive  
🔹 Excellent starting point for building automated, reusable data workflows in a Lakehouse architecture
