## 🧠 Key Concepts
🔹 Notebooks in Fabric support PySpark for scalable data processing  
🔹 Data can be ingested from CSV, JSON, or Parquet using Spark  
🔹 Spark DataFrames are used to explore and transform datasets  
🔹 Delta tables allow for managed, transactional storage in OneLake  
🔹 Spark SQL enables SQL-style queries over DataFrames

## 🔧 What I did
🔹 Opened a notebook and connected it to a Lakehouse  
🔹 Used PySpark to read data from CSV file in the Lakehouse Files section  
🔹 Explored the dataset with DataFrame methods  
🔹 Created a managed Delta table from the DataFrame  
🔹 Queried the table using Spark SQL inside the notebook

This module demonstrated how to combine notebooks, Spark, and Lakehouse in Fabric to ingest, transform, and query data at scale — all in a unified and accessible experience.
