## 🧠 Key Concepts
🔹 Dataflows Gen2 are cloud-based, low-code ETL tools built into Fabric  
🔹 Power Query is the engine for transformations  
🔹 Data is saved to OneLake as Delta tables (Lakehouse or Warehouse destinations)  
🔹 Supports multiple queries per dataflow  
🔹 Can be scheduled or manually refreshed

## 🔧 What I did
🔹 Created a blank Dataflow Gen2  
🔹 Connected to a data source and transformed the data using Power Query Online  
🔹 Published the result to a Lakehouse table  
🔹 Tested output schema and destination  
🔹 Explored integration with Notebooks and Power BI

## 📌 Summary
Dataflows Gen2 are a powerful and scalable ETL solution in Microsoft Fabric. They simplify data ingestion and transformation across teams and support integration across Fabric components.
