## 🧠 Key Concepts
🔹 Data can be loaded into a Fabric Warehouse using Dataflows Gen2 or Pipelines  
🔹 Copy activity is used to ingest data from multiple sources (CSV, SQL, Lakehouse)  
🔹 You can create new tables or load into existing ones  
🔹 Mapping columns and defining schemas is essential for accurate ingestion  
🔹 Monitor data pipeline execution using Fabric's monitoring tools

## 🔧 What I did
🔹 Created a data pipeline to load CSV data into a Fabric Warehouse  
🔹 Used Copy Data activity and mapped source columns to the target schema  
🔹 Created a new destination table via the pipeline UI  
🔹 Triggered and monitored the pipeline run  
🔹 Verified the data using SQL queries on the Warehouse endpoint

## 📌 Summary
Loading data into a Fabric Warehouse is simple and powerful. Whether using Pipelines or Dataflows, the ability to control ingestion, define mappings, and monitor runs makes it ideal for structured analytics.
