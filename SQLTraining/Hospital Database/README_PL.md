# 🇵🇱 README – Baza Szpitalna (Projekt treningowy SQL)

**Autor:** Piotr Urban  
**Wyzwanie:** [#90DaysDataAnalystChallenge](https://github.com/PiotrUr/90DaysDataAnalystChallange)

### 🏥 Opis projektu

Projekt stanowi część tygodniowego sprintu nauki SQL. Wykorzystuje syntetyczny zbiór danych o zarządzaniu szpitalem, aby ćwiczyć realistyczne scenariusze analityczne. Celem jest rozwinięcie umiejętności w zakresie zapytań SQL oraz zrozumienie działania procesów w środowisku danych relacyjnych.

🔗 **Źródło danych:** [Hospital Management Dataset – Kaggle](https://www.kaggle.com/datasets/kanakbaghel/hospital-management-dataset)

### 🗂️ Struktura folderu projektu

```
Hospital Database/
│
├── data/
│   └── Hospital Database.db   ← Plik bazy SQLite używany w projekcie
│
├── hospital_analysis_session1.sql        ← Pierwsza sesja z podstawowymi zapytaniami
├── hospital_analysis_session2.sql        ← Zapytania średniozaawansowane
├── hospital_analysis_session3.sql        ← Trudniejsze zagadnienia (joiny, agregacja, funkcje okienkowe)
├── hospital_analysis_session4.sql        ← Mieszana sesja z różnorodnymi problemami
├── hospital_dml_exercises.sql            ← Zadania z zakresu DML (INSERT, UPDATE, DELETE)
├── hospital_sql_exercises_all.sql        ← Plik ćwiczeniowy z pytaniami bez odpowiedzi
├── README_EN.md                          ← Plik z informacjami o zawartości projektu w języku angielskim
└── README_PL.md                          ← Plik z informacjami o zawartości projektu w języku polskim
```

💡 Aby przećwiczyć SQL samodzielnie, użyj pliku `hospital_sql_exercises_all.sql`. Pytania są pogrupowane według sesji i zawierają informacje o pliku z rozwiązaniem.

📍 Ścieżka do bazy SQLite:
```
90DaysDataAnalystChallange/SQLTraining/Hospital Database/data/Hospital Database.db
```
