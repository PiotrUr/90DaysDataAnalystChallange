# 🇬🇧 README – Hospital Database (SQL Training Project)

**Author:** Piotr Urban  
**Challenge:** [#90DaysDataAnalystChallenge](https://github.com/PiotrUr/90DaysDataAnalystChallange)

### 🏥 Project Description

This project is part of a weekly SQL learning sprint. It uses a synthetic hospital dataset to simulate realistic healthcare data analysis scenarios. The goal is to practice SQL querying, explore hospital management processes, and build analytical intuition for working with structured data.

🔗 **Dataset source:** [Hospital Management Dataset – Kaggle](https://www.kaggle.com/datasets/kanakbaghel/hospital-management-dataset)

### 🗂️ Project Structure

```
Hospital Database/
│
├── data/
│   └── Hospital Database.db   ← SQLite database file used in the project
│
├── hospital_analysis_session1.sql        ← First query session (introductory)
├── hospital_analysis_session2.sql        ← Intermediate-level queries
├── hospital_analysis_session3.sql        ← Advanced queries (joins, aggregation, window functions)
├── hospital_analysis_session4.sql        ← Mixed session with diverse challenges
├── hospital_dml_exercises.sql            ← DML-only tasks (INSERT, UPDATE, DELETE)
├── hospital_sql_exercises_all.sql        ← Consolidated practice file with all questions (no answers)
├── README_EN.md                          ← File with information about content of the project in english
└── README_PL.md                          ← File with information about content of the project in polish
```

💡 Use the file `hospital_sql_exercises_all.sql` if you'd like to **practice SQL on your own** — questions are organized by session, with references to corresponding answer files.

📍 The SQLite database is located at:
```
90DaysDataAnalystChallange/SQLTraining/Hospital Database/data/Hospital Database.db
```
